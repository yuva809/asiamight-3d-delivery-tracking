# AsiaMight — Delivery Tracking (standalone visual prototype)

A 3D logistics control tower for `/delivery-tracking`: the AsiaMight distribution centre on a **real Berlin map**
(OpenStreetMap), real driving routes (OSRM) to the **real AsiaMight branches**, animated warehouse operation,
delivery vans and a floating operations UI. **No backend**: all operational data is mock / simulated.

```bash
npm install
npm run dev            # http://localhost:3000 → /delivery-tracking
npm run typecheck && npm run lint && npm run build
```

## What you can do

- **Camera presets** (top bar): Overview · Warehouse · Loading · Network (all of Berlin) · Follow (chase a van on its route).
- **Building view**: Operational (translucent roof, front walls cut at door height) · Exterior · Inside (auto tour Storage → Picking → Packing → Loading).
- **Order flow demo** (bottom-left): New order → Picking → Packing → Loading → Ready → Dispatch, step by step or ▶ auto-play.
  Workers, the order pin, the docked van and the dock door react; dispatch sends VAN 03 along the real route to Hagelberger.
- Click/hover branches, vans or the warehouse for details; the right panel lists vans on the road, branches and docks.

## Architecture

```
features/delivery-tracking/        business data → visualization state (no three.js)
  types.ts                         Branch, Van (+ VanPlacement: dock | parking | route | gps), Delivery, Worker…
  mock-data.ts                     real branches, mock fleet/drivers/deliveries/workers
  mock-operations.ts               in-browser mock "backend": van progress, ETAs, arrivals, demo order flow
  use-delivery-tracking-data.ts    the ONE data entry point (swap for API/WebSocket in Phase 2)
  simulation.ts                    SimulationState + simulationDirectives() (pure)
  status-visuals.ts                VanStatus/DeliveryStatus → visual props
  worker-routines.ts               worker behaviour as data (walk/pick/pack/place/idle)
  scene-layout.ts                  site layout, docks, zones, camera presets
  geo.ts · berlin-geo.ts · route-math.ts   projection, map-data loader, polyline sampling

three/delivery-tracking/           presentational 3D only
  delivery-tracking-3d.tsx         Canvas root; resolves placements → poses
  city/                            CityMap (roads/water/parks/rail), CityBuildings, StreetDetails, RouteLines, ribbon shader
  warehouse.tsx · warehouse-interior.tsx · storage-shelves.tsx · packing-station.tsx · equipment.tsx · site-grounds.tsx
  worker.tsx (routine player) · delivery-van.tsx · use-van-motion.ts (route following / GPS easing)
  branch.tsx · map-pin.tsx · camera-controller.tsx · environment.tsx · scene-label.tsx

components/delivery-tracking/      floating UI: top bar, KPIs, operations panel, order flow, map tools, inside tour, fallback map
```

Flow for Phase 2/3: `backend event → store (same shape) → status-visuals / simulationDirectives → props → animation`.
`useVanMotion` already accepts `targetPosition` (GPS easing) and `route + progress`.

## 3D assets (CC0)

| Asset | Source | Use |
|---|---|---|
| `public/models/worker.glb` (486 KB) | Quaternius "Worker" (poly.pizza, CC0) — rigged, Idle/Walk/Run/Interact/Wave | all warehouse workers + pedestrians (role-tinted, carry pose layered on Walk) |
| `public/models/pallet.glb` (4 KB) | Quaternius "Pallet" (CC0) | instanced in racking + staging |
| `public/models/car-*.glb` (~25 KB each) | Kenney Car Kit (CC0), texture desaturated to a neutral palette | background city traffic only |

Pipeline: downloaded packs → `gltf-transform` (drop unused clips, dedup/weld/quantize, **Meshopt** compression,
embed texture) → `public/models`. drei's `useGLTF` decodes Meshopt automatically. The hero AsiaMight van stays
procedural on purpose: the free kit's vans read as toys; swap in a purchased/commissioned GLB later via the same
`useGLTF` path.

## Rendering & motion

- Post-processing (`@react-three/postprocessing`): N8AO ambient occlusion in screen-space radius (works from 1 m to
  25 km), bloom only on HDR emissives (lamps, headlights), SMAA, vignette, ACES tone mapping. Low-power: SMAA only.
- Lighting: late-afternoon warm sun with PCSS soft shadows (frustum follows the camera), cool sky fill, gradient sky
  dome + atmospheric fog, procedural environment for reflections.
- Materials: world-space procedural asphalt grain, paving/slab joints, cladding bump — no texture downloads.
- Camera: establishing shot on load (Berlin → warehouse), log-distance preset flights, chase-cam follow, occlusion-aware
  branch framing (raycasts against the city), slow ambient drift when idle. Reduced motion disables all of it.
- Workers: skeletal animation cross-fades (0.3 s), walk speed matched to ground speed, IK-style carry pose.
- Vans: acceleration/braking with suspension pitch, right-hand lane offset, plates, HDR lights.
- UI (`motion`): choreographed entrance during the establishing shot, spring number tickers, tabbed operations panel
  with cross-fading inspector, animated stepper, glass materials weighted by hierarchy, `MotionConfig reducedMotion="user"`.

Diagnostics: `?fx=noao,nosoft,nobloom,nopost,noshadow,expose` disables individual effects (and `expose` puts the R3F
state on `window.__amScene`) to measure their cost in any build.

## Performance notes

Merged/instanced geometry (≈2.5k real buildings in 2 draw calls, 2.1k street trees in 2), roads drawn as
ribbons whose width is real up close and screen-space when zoomed out, painter-ordered flat ground layers,
one shadow-casting sun whose frustum follows the camera, adaptive DPR, street detail hidden when zoomed out,
lazy-loaded 3D chunk, reduced-motion support and a flat SVG map fallback without WebGL.
Measured on an Apple M2 (production build), synchronous frame cost incl. GPU at 1.25× DPR while on battery at
18 % (throttled): ~19 ms all effects on (base scene ~10 ms, AO ~4 ms, bloom+SMAA+grade ~5 ms). Adaptive quality
steps DPR down to 1.0 and then switches AO off on genuinely slow devices; it deliberately ignores the 30 fps cap
browsers apply in battery-saver mode. Re-measure on mains power with `?fx=` flags.
